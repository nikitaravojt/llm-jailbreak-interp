# Tracking LLM Refusal and Harmfulness Representations During Adversarial Jailbreak Optimisation

Code and experimental notebooks for my MSc Computer Science (Artificial Intelligence) dissertation at the University of Nottingham.

The repository contains the notebooks and scripts used throughout the project. The code reflects an iterative, exploratory research process rather than a polished software package, so some duplication, intermediate experiments, environment-specific paths and development artefacts are kept. The notebooks are ordered roughly chronologically and do build on each other, and show how the final methodology and analysis were developed.
